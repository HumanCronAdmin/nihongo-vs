# NihongoVS

Side-by-side Japanese grammar comparisons for English-speaking learners. Clear explanations, example sentences, and memory tips for JLPT N5-N1.

## Features

- 50+ grammar comparisons (は vs が, から vs ので, etc.)
- 8 anime speech archetypes (tsundere, ojou-sama, etc.)
- JLPT level filtering (N5–N1)
- Category browsing (daily life, formal, anime, etc.)
- Mobile-friendly, no signup required
